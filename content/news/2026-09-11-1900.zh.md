## 重点增量新闻

**1. 美、布两油续跌近5%——WTI触及96、布伦特触及101（18:20 CST · 金十）**

布伦特原油向下触及101美元/桶，日内跌4.89%；WTI原油向下触及96美元/桶，日内跌4.51%。原油从开盘100.67一路下行，18:00后跌幅继续扩大。（金十 ID 229903）**影响：这是今日原油最核心的行情事件。需求恶化定价（欧佩克连续五次下调需求预测）压过供给中断风险——即便胡塞已控制曼德海峡、沙特遭空袭升级，油价仍被需求侧拖累。WTI跌破96后向95整数关口靠近，短线波动率放大。**

**2. 俄罗斯央行维持利率14%不变，通胀展望上修（18:30 CST · 俄罗斯央行）**

俄罗斯央行周五将关键利率维持在14%不变，符合预期。央行同时上修2026年通胀展望至6.0%-7.0%（前值更低），指出"近期价格压力显著增加"、汽油价格上涨影响基础通胀。央行表示将"根据通胀及通胀预期的动态"进一步决策。（金十 ID 229899-229895）**影响：新兴市场利率路径的参考信号。14%的高利率反映了俄罗斯面临的地缘通胀压力——能源基础设施遭袭推升国内能源成本。对全球而言，这是"冲突成本内生化"的又一个案例，但俄罗斯并非OPEC核心产油国，对国际油价直接影响有限。**

**3. 欧盟委员会批准61亿欧元援乌资金（18:45 CST · 欧盟委员会）**

欧盟委员会11日批准向乌克兰提供61亿欧元资金，用于采购防空反导系统、弹药、无人机和电子战系统等。资金将支持从欧盟和乌克兰企业采购国防产品。（金十 ID 229905）**影响：国防板块获得持续的政策背书。欧洲军费开支持续加码，欧洲防务股（如BAE、莱茵金属等）基本面支撑稳固。但61亿欧元对防务巨头营收影响有限，更多是政治信号——欧盟援乌力度未因疲劳感减弱。**

**4. BMO下调甲骨文目标价从220美元至195美元（18:50 CST · 蒙特利尔银行）**

蒙特利尔银行将甲骨文(ORCL.N)目标价从220美元下调至195美元。（金十 ID 229911）**影响：AI基础设施标的遭机构下调目标价，叠加此前美银对AI投入产出比的质疑，市场对AI资本开支可持续性的分歧在加大。ORCL本身当日走势需关注开盘反应，但信号意义大于个股影响——"AI花费是否值得"正从散户叙事变成机构分歧点。**

**5. 乌克兰称已袭击俄罗斯萨拉托夫石油炼油厂（18:38 CST · 乌方消息）**

乌克兰方面称已袭击俄罗斯萨拉托夫石油炼油厂。萨拉托夫位于俄罗斯腹地，距乌克兰边境约1,000公里。（金十 ID 229893）**影响：这是冲突向俄罗斯能源基础设施纵深扩展的信号。但与沙特/红海事件不同，俄罗斯炼油厂遭袭对国际原油供给的直接影响较小——俄罗斯原油出口主要通过管道和北极港口，内陆炼油厂不是国际油价的直接供给端。不过，这进一步推升俄罗斯国内汽油价格（央行声明已确认），加大俄通胀压力。**

## 局势研判

**原油——需求定价压倒供给风险，95是关键多空分水岭。** WTI从100上方跌至95.72、日内跌幅近5%，布伦特同样跌破103至101附近。**判断：这是典型的"需求恐惧 > 供给中断"格局。** 胡塞控制曼德海峡、沙特空袭也门、乌克兰袭击俄罗斯炼油厂——供给端风险事件密集，但油价不涨反暴跌，说明市场当前对全球贸易量萎缩和能源需求下行的担忧远大于红海绕行成本。欧佩克连续五次下调需求预测是核心背景。策略：短线95美元是WTI的心理和技术双重支撑，跌破可能触发止损盘加速下行至92-93区间；站稳则维持95-100区间震荡思维。CPI前不宜追空，但反弹乏力条件下也不宜做多。

**黄金——利率预期主导方向，4,300-4,360区间仍未破。** 黄金从上一期的4,347回落至4,339，日内仍录+0.53%涨幅，高4,360/低4,300。（金十数据）**判断：黄金的区间震荡格局延续。4,300的三次测试确认了强买盘支撑，但30Y美债收益率创19年新高压制了黄金的上行空间。利率与地缘的双向拉扯下，黄金缺乏单边突破的动力。CPI是唯一可能打破平衡的变量——低于预期则有望挑战4,360-4,400，超预期则4,300可能再次承压。策略：区间思维不变，4,300附近偏多、4,360附近偏空，CPI前不赌方向。**

**权益市场——CPI前缩量防守，AI叙事分歧加大。** 美银报告指出过去三周美股基金流出142亿、全球股基流入从520亿骤降至70亿；BMO同日下调ORCL目标价；Markets Pulse调查显示30%机构认为10Y破5%可触发美股10%回调。（金十数据综合）**判断：资金在CPI前已经提前降险。142亿流出量级虽未到恐慌，但配合AI标的机构分歧加大（美银质疑全要素生产率、BMO下调ORCL），权益市场在CPI前缺乏向上动力。策略：CPI前以防守为主，不追高、不加仓。若CPI低于预期且10Y回落，超跌成长有反弹窗口；若CPI超预期破5%利率阈值，需警惕程序化卖盘。**

**欧洲能源——冬季库存缺口持续，但短期无催化剂。** 欧盟天然气库存67.64%，距冬季90%目标缺口超100TWh。荷兰TTF本周涨12%。（金十 ID 229879）**判断：这是Q4的确定性风险但非今日短线变量。欧洲天然气库存差距不会在几小时内缩小，TTF的高波动反映的是秋季注气进度的担忧。对美股LNG出口商（REGS、TRGP等）构成中长期支撑，但短线欧洲股市已收盘、亚太早盘平淡。策略：关注周末是否有欧洲紧急注气政策出台，作为下周一LNG相关标的的交易依据。**
