## 3. 信号分析

### 信号一：AI 工具的"成本天花板"已经到来

- **信号**：Uber 限制每人每月 $1,500 AI 费用
- **逻辑链**：企业 AI 采用率在涨，但付费意愿有上限 → AI SaaS 公司的提价空间受限 → 需要靠量而非价来增长
- **相关标的**：MSFT（GitHub Copilot）、GOOG（Gemini Enterprise）、CRM（Agentforce）

### 信号二：AI Agent 基础设施层爆发

- **信号**：headroom（token 压缩）、codegraph（代码图谱）、agent-governance-toolkit（治理）三个 Agent 基础设施项目同时爆发
- **逻辑链**：AI Agent 从概念走向生产需要完整的基础设施栈 → 压缩、索引、治理是刚需 → 基础设施供应商受益
- **相关标的**：MSFT（Azure Agent Stack）、GOOG（Vertex AI Agent Builder）、NVDA（推理算力需求）

### 信号三：开源模型竞争白热化

- **信号**：Gemma 4 开源 + MOSS-TTS 开源，闭源模型定价权持续被侵蚀
- **逻辑链**：开源模型能力逼近闭源 → API 价格战 → 纯模型层公司承压 → 有平台生态的公司（MSFT/GOOG/META）更能抵御
- **相关标的**：META（Llama 开源生态）、GOOG（Gemma 开源）、MSFT（Foundry 平台汇聚 12000+ 模型）
