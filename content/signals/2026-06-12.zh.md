**信号一：能源转型加速 → 新能源 vs 传统能源分化**
- 逻辑链：太阳能首次超越煤炭发电 → 可再生能源装机趋势不可逆 → 传统煤电资产加速减值
- 潜在影响：利好 First Solar（FSLR）、Enphase Energy（ENPH）等光伏股；利空煤炭板块（BTU、ARCH）
- 关注点：下周可观察光伏 ETF（TAN）资金流向

**信号二：AI Agent 生态爆发 → Agent 基础设施需求激增**
- 逻辑链：GitHub 周榜前三均为 AI Agent 相关项目，NousResearch hermes-agent 单周新增 1 万星 → Agent 框架标准化、工具链成熟 → 企业 AI Agent 部署进入加速期
- 潜在影响：利好 NVIDIA（NVDA）GPU 需求、Cloudflare（NET）边缘计算、以及 AI 基础设施提供商
- 关注点：关注 Agent 平台类公司（如 Salesforce 的 Agentforce）季度数据

**信号三：Anthropic 产品信誉风险 → 闭源 AI 估值承压**
- 逻辑链：Claude Fable "隐形护栏"争议 + 编码评测低于预期 → 用户信任下降 → 开源替代方案加速追赶（DeepSeek-R1 复现）
- 潜在影响：若 Anthropic 估值叙事受损，可能波及整个闭源 AI 赛道的风险偏好；利好开源生态（Hugging Face 等）
- 关注点：跟踪 Anthropic 后续产品发布及企业客户反应
