## 信号分析

### 信号一：AI 推理成本断崖式下降 — 倒逼硬件路线分化

DeepSeek V4 Pro 成本仅为 Claude 的 1/46，1M 上下文窗口 + 峰谷定价。同一周内 Grok 4.6、Qwen3.8-2.4T、GLM-5.3、Mojo 1.0 集中发布。模型层竞争白热化推动推理成本加速下行。

**逻辑链：** 模型开源 + 价格战 → 推理需求暴增 → 通用 GPU 内存带宽成瓶颈 → 专用推理芯片价值凸显

**相关标的：**
- **NVDA** — 短期推理需求支撑量，但长期面临专用芯片分流风险（Groq 被 NVDA 以 $200 亿收购资产，AMD 买 Taalas 跟进）
- **AMD** — 收购 Taalas 刻入式推理芯片 + Helios 机架，推理路线差异化布局，对 NVDA 形成局部威胁
- **GOOGL / MSFT** — 云厂商是推理成本下降的最大受益方，margin 扩张预期

### 信号二：Stripe $70 亿收购 OpenRouter — AI 中间层整合加速

Stripe 以 $70 亿+收购 OpenRouter，较 82 天前 $13 亿估值溢价 5x+。OpenRouter 覆盖 400+ 模型、800 万开发者，年处理 1.5 万亿 token。这是 AI 中间层（model gateway / router）首次出现 10 亿美元级并购。

**逻辑链：** 模型碎片化加剧 → 需要统一路由层 → model gateway 成为战略资产 → 支付/计费入口被锁定

**相关标的：**
- **STRIP** — 非上市公司，但定价 OpenRouter 的战略价值：AI 时代的 Stripe = AI 计费基础设施
- **MSFT** — Azure 已有类似 model router 能力，OpenAI 独家关系是护城河
- **GOOGL** — Vertex AI Model Garden 覆盖多模型，但缺少 Stripe 级别的分发渠道

### 信号三：Agent 基础设施成为 GitHub 最大趋势 — 从模型到编排

本周 GitHub Top 20 中，超过一半项目与 AI Agent 编排相关（skills、agency-agents、prime-agent、orca、hermes-agent、superpowers）。社区从"模型能做什么"转向"如何可靠地运行多 Agent"。

**逻辑链：** 模型能力已足够强 → 瓶颈在编排/记忆/技能复用 → Agent infra 层爆发 → 应用层创业门槛降低

**相关标的：**
- **CRM** — Salesforce Agentforce 是企业 Agent 平台先发者
- **MSFT** — Copilot Studio + Semantic Kernel 持续投入 Agent 框架
- **MDB** — MongoDB 作为 Agent 记忆层，vector search + 文档存储天然适配
- 做多 Agent infra 生态受益方，做空"纯模型层 wrapper"创业公司
