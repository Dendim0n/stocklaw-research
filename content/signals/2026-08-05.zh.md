## 信号分析

**信号一：Edge/端侧 AI 推理加速——GPU 垄断格局松动**

逻辑链: DeepSeek V4 单卡 MI300X 可运行 + airllm 在 4GB 显存跑 70B + Maple-Preview 在 iPhone 上 20B MoE 达到 120 tok/s → AI 推理不再绝对依赖高端 NVIDIA GPU，AMD 在推理场景有竞争力，端侧推理正在成为现实 → 相关标的: **AMD**（MI300X 需求验证）、**NVDA**（垄断溢价可能收窄）、**AAPL**（端侧 AI 生态强化）

**信号二：AI Agent 基础设施快速成熟——新支出周期启动**

逻辑链: 腾讯推出 Agent 记忆中枢 + Uber 内部部署 ADR Agent 安全工具 + 多个 Agent 框架项目登上 GitHub Trending（openwork、jcode 等） → AI Agent 从概念走向生产部署，企业开始构建 Agent 基础设施层 → 相关标的: **MSFT**（Copilot/Agent 生态）、**CRM**（Agentforce）、**NOW**（AI Agent 工作流）、**MDB**（Agent 数据层）

**信号三：AI 驱动网络安全威胁升级——网安支出逻辑强化**

逻辑链: Interpol 报告 AI 驱动非洲过半网络犯罪 + OpenAI 发布第三方网络安全评估 + Palo Alto 发布 Passkey 攻击面研究 → AI 降低攻击门槛，企业防守成本被迫上升，网络安全预算优先级提升 → 相关标的: **PANW**（端到端安全平台）、**CRWD**（云原生安全）、**FTNT**（网络边界安全）
