## 三、信号分析

**信号 1：推理成本持续下探，竞争焦点从训练转向部署端**
unsloth、llmfit、needle、onnxruntime 本周集体霸榜，配合 HN 上"0.6 美元芯片跑 Photoshop"。
逻辑链：开源权重 + 本地/端侧推理成熟 → 单位推理成本快速下降 → 对高端 GPU 的 ASP 形成长期压力，但短期算力需求仍由前沿训练和自动驾驶（Waymo）支撑 → 相关标的：NVDA（出货 vs 定价双线）、苹果/高通（端侧 AI 受益）、AI 应用层毛利修复。
置信度：中高。方向明确，但节奏难以精确。

**信号 2：中国 AI 开源加速（DeepSeek 视觉模型 + 字节 Agent 基建）**
DeepSeek v4-flash-vision-exp 上线 + 火山引擎 OpenViking 一周 +3k 星。
逻辑链：中国开源模型持续领先迭代 → 开源权重对闭源 API 的价格压力加大 → 利空以 API 定价为主的闭源厂商，利好云厂商/应用层成本端 → 相关标的：云厂商成本端、NVDA 出货量逻辑（中国厂商持续采购训练算力）。
置信度：中。开源对中国厂商自身商业化反而是压力。

**信号 3：AI 生产力叙事进入验证期 + 劳动力市场偏弱**
Economist 研究（作业分↑考试分↓）+ HN "AI-blind" 疲劳感（252 票）+ WSJ 虚假招聘广告泛滥。
逻辑链：市场从"AI 潜力"转向"AI 实际产出"验证 → 若后续实证继续偏负面，高估值 AI 标的估值承压；同时就业信号偏弱若被硬数据确认，则降息预期升温，利好利率敏感与中小盘 → 相关标的：高估值 AI 龙头（回调风险）、利率敏感板块（降息受益）。
置信度：中低。负面结论目前以单一来源为主，需交叉验证。
