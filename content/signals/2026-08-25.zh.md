## 3. 信号分析

### 信号一：中国算力自主化加速，出口管制边际效用递减
**逻辑链**：小米 CPU 单核追平 Apple、多核大幅领先 + CUDA 官方支持 RISC-V → 国产芯片从"能用"到"好用"拐点临近，美国出口管制对中国算力供给的钳制力下降 → 中国云厂商/互联网的国产替代采购加速，海外芯片厂商的中国区收入敞口收窄。
**相关标的**：AMD、INTC 的中国区营收风险上升；NVDA 长期竞争格局变量（国产替代 + RISC-V 开放生态）。

### 信号二：AI 推理成本崩塌，量增价跌的两头挤压
**逻辑链**：OpenAI GPT 5.6 Sol 主动降价 + GitHub 上免费/开源 coding agent 与免费 LLM 聚合端点爆发（free-claude-code、freellmapi 等）→ 推理单位成本陡降、模型层变现被压缩 → 受益方转向"用量更大"的应用层和算力层，模型层毛利承压。
**相关标的**：NVDA（以量补价，推理需求总量扩张）；模型/应用层公司毛利率面临下行；High Bandwidth Flash（HBF）上量的背景下，存储链（如 Micron 相关）受益于带宽瓶颈。

### 信号三：Agent 基础设施层成形，企业 AI 从 demo 进入生产
**逻辑链**：Agent 记忆数据库（OpenViking）、插件市场（claude-plugins-community、cursor/plugins）、Apache 孵化 agent 工作区（maka）、微软 Agent Lightning → 企业 agent 需要的内存、工具分发、可审计运行层开始标准化 → 平台型公司吃下这波"agent 中间件"红利。
**相关标的**：MSFT（Agent Lightning/Copilot 生态）、CRWV（企业 agent 平台）、以及数据/可观测性基础设施供应商。
