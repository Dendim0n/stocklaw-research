## 信号分析

### 信号一：AI 模型商品化加速，推理成本结构性下降

DeepSeek V4 Flash 引发性能/价格热议，Kimi K3 可在 29GB 内存本地运行，OmniRoute 提供 290+ 模型统一接入——开源 AI 模型正在以更快速度逼近闭源前沿，且推理门槛持续降低。

逻辑链：开源模型性能提升 → 推理市场价格战加剧 → 云厂商 AI 利润率承压 → 算力需求总量增长但单价下降（量增价跌）

相关标的：NVDA（推理需求量增但 ASP 压力）、MSFT/GOOG/AMZN（AI 服务毛利分化）、AMD（推理算力替代需求）

### 信号二：AI Agent 基础设施层快速成型

本周 GitHub 趋势中，Agent 工具链项目密集爆发——GitHub Copilot SDK、OpenWork（开源 Claude Cowork 替代）、ego-lite（Agent 浏览器自动化）、pi（Agent 工具包）等同时上榜。Agent 不再是概念，而是正在形成完整基础设施层。

逻辑链：Agent 基础设施成熟 → 企业级 Agent 部署门槛降低 → SaaS 软件生产率颠覆加速 → 传统企业软件估值面临重估

相关标的：MSFT（Copilot 生态最大受益者）、CRM/NOW/WDAY（传统 SaaS 面临颠覆风险）、MDB/ESTC（AI 基础设施需求）

### 信号三：AI 安全与出口管制升温

Tailscale 复盘 Hugging Face 入侵事件获 401 票高关注度，同时"模型权重是新密码学"讨论反映 AI 出口管制正在成为政策焦点。两条线交汇指向同一方向：AI 安全监管即将收紧。

逻辑链：AI 供应链安全事件频发 → 监管层加码 AI 安全合规 → 网络安全支出加速 + 模型出口管制细化 → NVDA/AMD 对华出口政策不确定持续

相关标的：PANW/CRWD（网络安全支出加速）、NVDA/AMD（出口管制政策风险）、PLTR（AI 安全合规受益）
