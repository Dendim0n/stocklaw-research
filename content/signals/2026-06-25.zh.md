## 三、信号分析

**信号 1：AI 算力供应链从"独占 NVIDIA"走向多元化**
OpenAI 选择 Broadcom 而非 NVIDIA 代工首款自研芯片，结合 Qualcomm 收购 Modular 强化边缘 AI，说明头部玩家正在主动降低对单一供应商的依赖。
→ **可能影响：** NVDA 短期不受实质冲击（自研芯片量产仍需时间），但长期估值逻辑需纳入"客户流失"风险；AVGO 受利好（代工订单落地）；VRT 等散热供应链受益于液冷方案推广。
→ **关注标的：** NVDA、AVGO、QCOM、VRT

**信号 2：AI agent 从"对话工具"进化为"自主操作系统"**
Google 给 Gemini 3.5 Flash 加 computer use 能力，GLM-5.2 在开源 agent 领域实现阶跃，GitHub 上 agent 基础设施项目（harness、SkillSpector、codebase-memory-mcp）集体爆发。
→ **可能影响：** AI agent 赛道从概念验证进入规模化部署，SaaS 行业面临被 agent 替代的风险；网络安全需求同步增长（agent 可操作电脑 = 攻击面扩大）。
→ **关注标的：** GOOG/GOOGL（Gemini agent）、PANW/CRWD（网络安全）、CRM（SaaS 被替代风险）

**信号 3：企业 AI 转型的"阵痛期"信号——Elastic 裁员**
Elastic 裁员 7% 不是个案。当 AI agent 能高效完成日志分析、搜索增强等工作时，传统 DevOps 工具公司的价值主张需要重新定义。
→ **可能影响：** 科技公司进入"AI 替代内部岗位"的组织调整期，部分中小市值工具股面临估值压缩；但同时催生 AI 原生工具的需求。
→ **关注标的：** ESTC（直接承压）、DDOG（同类竞争）、AI/PLTR（受益于企业 AI 转型需求）
