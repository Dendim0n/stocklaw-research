# 【每周一】NVIDIA 循环融资风险监控 | 2026-06-29

## 本周是否有重大变化

**本周核心风险等级：中高 → 高** ⚠️

本周出现两个值得关注的信号：
1. **OpenAI Q1 2026 烧钱数据曝光**：Q1 亏损 $37 亿，超过同期 $57 亿收入的一半，全年预计亏损 $140-170 亿
2. **CoreWeave Q1 业绩低于预期**：营收虽翻倍至 $20.8 亿，但 EPS 亏损 $1.12（预期亏 $0.90），2026 资本开支上限上调至 $350 亿，股价盘后跌 10%

这两个信号直接加深了"循环融资"链条的脆弱性。

---

## 一、NVIDIA 关联方交易

| 指标 | 数据 |
|------|------|
| 承诺投资总额 | $1,100 亿（含对 OpenAI $1,000 亿） |
| GPU 担保债务敞口 | $150 亿+（CoreWeave $104.5 亿 + Lambda $5 亿等） |
| 对 CoreWeave 持股 | $30 亿（2026 年初追加 $20 亿） |
| 投资组合占年收入比 | 67%（$1,100 亿 vs $1,650 亿 LTM 收入） |

**分析：** NVIDIA 的关联方交易结构已从"供应商融资"演变为"资本循环"——NVIDIA 投资 OpenAI → OpenAI 承诺购买 NVIDIA GPU → NVIDIA 收到回流现金。OpenAI CFO Sarah Friar 曾确认"大部分资金会流回 NVIDIA"。Bloomberg 2026 年 1 月专题报道将此称为"AI 繁荣的循环交易"。SSRN 2026 年 4 月学术论文直接将其类比 2000 年 Lucent 的供应商融资模式，NVIDIA 的敞口是 Lucent 的 2.8 倍。

**风险信号：** 高。客户集中度是 Lucent 时代的 1.7 倍（前 2 大客户占 39% vs 23%），且资金回流路径高度重叠。

## 二、OpenAI 财务状况

| 指标 | 数据 |
|------|------|
| Q1 2026 收入 | $57 亿 |
| Q1 2026 亏损 | $37 亿（烧钱率 > 60% 收入） |
| 2026 全年预计亏损 | $140-170 亿 |
| 最新融资 | $1,100 亿（2026.2 公布，$7,300 亿估值） |
| 算力支出承诺 | $6,650 亿（至 2029 年） |
| Stargate 项目 | $5,000 亿（4 年计划） |

**分析：** OpenAI 是 NVIDIA 循环融资链条中最脆弱的一环。Q1 烧钱 $37 亿意味着全年可能突破 $170 亿（The Economist 原始预测）。$1,100 亿新融资中，NVIDIA 承诺 $300 亿、SoftBank $300 亿——这些资金中的大部分将通过 Stargate 项目回流至 NVIDIA 硬件采购。关键问题：OpenAI 何时能实现自我造血？目前看不到路径。$6,650 亿的算力支出承诺如果收入增长不及预期，将构成巨大的"坏账"风险敞口。

**风险信号：** 极高。OpenAI 是整个循环的"需求端"，如果其商业化进展受阻，链条将面临系统性压力。

| Q1 2026 EPS | 亏损 $1.12（预期亏 $0.90） |

| 总债务 | ~$250 亿 |
| 收入积压订单 | $994 亿 |
| 2027 年化收入目标 | >$300 亿 |

**分析：** CoreWeave 陷入典型的"高增长+巨亏"困境。Q1 营收翻倍但亏损扩大，S&P 将信用评级上调至"正面"但债务已膨胀至 $250 亿。$310-350 亿的资本开支计划意味着持续烧钱。关键风险：62% 收入来自微软（2024 年数据），客户集中度极高。NVIDIA 持股 $30 亿 + CoreWeave 每年从 NVIDIA 采购大量 GPU = 典型的循环。如果 CoreWeave 无法在 2027 年实现 $300 亿年化收入，其债务偿还能力将受到严重质疑。

**风险信号：** 高。资本开支飙升 + 亏损扩大 + 高负债 = 脆弱性持续累积。

## 四、循环融资风险信号

**本周新增分析：** Buxton Helmsley（2026.5.29）发布深度报告《The Circular Bargain》，系统性梳理了 AI 生态的循环交易结构：

| 循环环节 | 交易结构 | 风险 |
|----------|----------|------|
| NVIDIA → OpenAI | $1,000 亿投资（分 10 期），OpenAI 承诺部署 NVIDIA 基础设施 | 资金回流闭环 |
| AMD → OpenAI | 提供 6GW Instinct GPU + 1.6 亿股认股权证（$0.01 行权价），行权条件绑定 GPU 采购 | 需求人为制造 |
| CoreWeave → NVIDIA | CoreWeave 采购 NVIDIA GPU → NVIDIA 持股 CoreWeave → CoreWeave GPU 担保贷款 | 多层杠杆叠加 |
| 整体生态 | 2026 年 AI capex 预计 $650-700 亿（是电信泡沫时代的 3-5 倍实际值） | 系统性过热 |

**与电信泡沫对比：**
- Lucent 2000 年供应商融资 $81 亿 = 收入的 24%
- NVIDIA 当前 $1,100 亿 = 收入的 67%（**2.8 倍于 Lucent**）
- 客户集中度：NVIDIA 前 2 大客户占 39% vs Lucent 的 23%
- 关键差异：NVIDIA 经营现金流 $154 亿（Q2 FY26），远强于 Lucent 的 $3 亿

**核心问题：** 如果停止供应商融资，有多少"需求"是真实独立的？

**风险信号：** 极高。循环结构已形成自我强化但脆弱的闭环。

| 芯片 | 厂商 | 代数 | 状态 | 对 NVIDIA 威胁 |
|------|------|------|------|----------------|
| TPU Ironwood | Google | 第 7 代 | GA（2025.11），GKE 已支持 | 高：推理效率提升 10x，Meta 考虑 2027 年部署 |
| Trainium 3 | Amazon | 第 3 代 | EC2 Trn3 可用，3nm/144GB HBM3E | 中高：仅限 AWS 内部，生态锁定 |
| Maia 200 | Microsoft | 第 2 代 | 2026.1 发布，声称性能 3x Trainium | 中：仅限 Azure，生态锁定 |
| MTIA | Meta | - | 内部部署 | 中：仅限 Meta 自用 |

**关键发现：** 推理工作负载已占 AI GPU 支出的 60-80%。Hyperscaler 自研芯片的目标是从 NVIDIA 手中夺回内部推理份额（当前约 90%），预计 2028 年降至 20-30%。但关键限制：**这些芯片不对外出售**——如果 AWS、Google、Microsoft、Meta 不是你的云提供商，这些芯片对你不存在。

**对 NVIDIA 的影响：**
- 短期（2026-2027）：影响有限，因为自研芯片主要替代 hyperscaler 内部推理工作负载
- 中期（2028+）：推理份额可能从 90% 降至 20-30%，训练仍是 NVIDIA 主场
- 长期风险：如果 hyperscalers 将自研芯片能力"解锁"对外出售，将直接冲击 NVIDIA GPU cloud 生态

**风险信号：** 中。短期可控，但中长期侵蚀不可忽视。

## 核心结论

1. **OpenAI 是链条最脆弱环节**：Q1 烧钱 $37 亿，全年可能亏损 $170 亿。$1,100 亿新融资中 NVIDIA 贡献 $300 亿——这笔钱大概率通过 Stargate 项目回流至 NVIDIA GPU 采购。如果 OpenAI 的商业化（API 收入、企业订阅）增长不及预期，整个循环将面临断裂风险。

2. **CoreWeave 的债务炸弹在膨胀**：$250 亿债务 + $310-350 亿资本开支 = 持续高杠杆运营。NVIDIA 持股 $30 亿 + CoreWeave 每年采购 NVIDIA GPU = 典型的供应商融资闭环。Q1 EPS 亏损 $1.12 超出预期，Q2 指引低于市场预期。

3. **学术界开始系统性警告**：SSRN 2026.4 论文、Bloomberg 2026.1 专题、Buxton Helmsley 2026.5 深度报告——三条独立路径指向同一结论：AI 生态的循环融资结构与 2000 年电信泡沫高度相似，但规模是 3-5 倍。

4. **自研芯片是定时炸弹**：Google TPU Ironwood 已 GA、Microsoft Maia 200 发布、Amazon Trainium 3 可用——推理份额侵蚀路径已清晰。2028 年 NVIDIA 推理份额可能从 90% 降至 20-30%。

5. **NVIDIA 的"安全垫"**：经营现金流 $154 亿远强于 Lucent 时代，且 GPU 仍是训练工作负载的绝对垄断。但 67% 收入占比的投资敞口是不可忽视的尾部风险。

**建议关注：** OpenAI Q2 财报（烧钱趋势是否加速）、CoreWeave Q2 业绩（$250 亿债务的利息覆盖率）、NVIDIA FY27 Q1 财报（关联方交易披露细节）。
