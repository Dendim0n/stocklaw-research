## Signal Analysis

### Signal 1: Agent Skills Ecosystem Is Exploding — AI Competition Shifts from Models to Toolchains
GitHub daily and weekly charts are dominated by agent skills, plugin marketplaces, and coding agents (archify, claude-plugins, cursor/plugins, openai/codex, scientific-agent-skills).
Logic chain: model capability convergence → differentiation shifts to agent toolchains and workflow standardization → lower enterprise AI adoption barriers and broader adoption.
Related names: AI application layer (CRM/office/vertical software) and cloud vendors; the key question is whether value accrues to the "picks and shovels" infrastructure (AWS/MSFT/GOOGL) or the application layer. Higher token consumption from agents is a tailwind for compute demand.

### Signal 2: Open-Source Models + Inference Cost Declines Converge, Pressuring Closed-Source Pricing
Tencent open-sourcing Hy4, vLLM 0.28 iteration, and free LLM aggregators (freellmapi, 7.4B tokens/month, ~+2.7k stars/week) appeared simultaneously.
Logic chain: open-source capability closing the gap + free/cheap inference supply → weakened closed-source API pricing power → but agent adoption expands total token consumption, a "volume up, price down" dynamic.
Related names: compute demand side still benefits (NVDA and cloud); pure API monetization models face near-term gross margin pressure — distinguish "selling compute" from "selling API."

### Signal 3: Compute-in-Memory Heats Up — Memory/Storage Chain Repricing
Samsung PIM (Hot Chips 2026) led HN with high votes, alongside active HBM/storage discussion.
Logic chain: PIM moves compute into memory → reduces data movement, big efficiency gains → memory vendors shift narrative from "selling capacity" to "selling compute."
Related names: MU (Micron) and the HBM supply chain; a long-term architectural variable for the GPU ecosystem — not a near-term threat, but worth adding to the watchlist.
